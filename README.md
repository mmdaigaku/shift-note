# シフトノート v2

## 使い方
1. `index.html` をブラウザで開きます。
2. バイト名・時給・割増率を入力して「勤務先を登録」を押すと次回以降選択できます。
3. 勤務を入力して「この勤務を保存する」を押します。
4. 「集計月」で表示月を選ぶと月の給与合計・勤務履歴・直近6か月のグラフが表示されます。

## 前バージョンの記録を残すには
同じブラウザ・同じサイトのURLで開く必要があります。`file://` で開く場合、ファイルの場所が変わると記録を引き継げない場合があります。先に旧版の「CSVで保存」でバックアップしてください。CSVのインポート機能はありません。

## 注意
概算の計算ツールです。残業・休日割増、交通費、控除などは未対応。休憩は1区間のみです。データはブラウザのlocalStorageに保存されます。
